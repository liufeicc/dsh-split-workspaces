# 多工作区平铺 · 科幻节点版（静态概念稿）

这是 `dsh-split-workspaces` 的第二种视觉概念稿。上一版古纸手稿已删除，
这一版改为参考「任务分派」界面的科幻 HUD 风格，但**保留四栏平铺的布局**，
不是把平铺面板改成任务分派画布。

## 打开方式

直接双击 `index.html`，或在当前目录起一个静态服务：

```bash
cd dsh-split-workspaces/mockups/scifi
python3 -m http.server 8766
# 浏览器打开 http://127.0.0.1:8766/
```

截图：`preview.png`（1920 × 1080）。
动效演示：`preview.gif`（960 × 540，从 15 个动画时间点截帧合成，
所以它只截取了持续动效的一小段；入场、鼠标柔光要直接打开页面看）。

## 设计语言

一句话：**四个并行会话，像四块悬浮在深空网格里的终端节点。**

- **背景**：近黑蓝底 + 点阵网格 + 大网格线 + 极淡横向纹理 + 青色/紫色环境光。
- **节点外壳**：深蓝黑玻璃面板，1px 冷蓝描边，左上/右上 L 形角标，
  右上角一个连接端口圆点；节点内部叠一层极淡的点阵。
- **状态**：活动节点是橙色描边 + 橙色外发光（对应任务分派里「运行中」的卡片）；
  其他节点青色描边。状态 pill 用颜色区分 RUNNING / PAUSED / REVIEW / BLOCKED。
- **顶部**：HUD 顶栏 + 系统状态条，状态条左侧一条青色竖线，保留参考图里的
  「说明条」结构。
- **内容**：终端式代码块（红/黄/绿三个小点 + bash 标签）、遥测面板、
  数据条、运行日志、任务卡、红色错误块、命令行输入区（`›` 提示符）。
- **分隔**：窗格之间不是普通拖拽条，而是一条发光竖线 + 中间的菱形节点。
- **色板**：青 `#4dd7ff`、橙 `#ff7a1a`、红 `#ff4d6d`、紫 `#a78bfa`、绿 `#3ddc97`。
- **字体**：Noto Sans CJK SC（界面）、Nimbus Mono PS（路径/代码/编号）。

## 动效

- 背景：点阵/大网格缓慢漂移、极光呼吸、星尘粒子（canvas，固定种子）。
- 鼠标：一圈跟随光标的柔光（实时模式）。
- 节点：四块依次入场；活动节点橙色光晕呼吸；沿边框旋转的流光；
  状态灯呼吸、端口脉冲。
- 分隔条：菱形呼吸，一条光点沿竖线上下跑。
- 数据：进度条加载时生长、之后流光；遥测条流动；终端末尾光标闪烁；
  命令提示符呼吸；发送键光晕；页脚信号条跳动。
- 顶栏：品牌图标呼吸、扫光，当前模式按钮光晕呼吸。
- 所有动画都受 `prefers-reduced-motion: reduce` 控制，系统开了「减少动态」会直接停掉。

## 与任务分派参考图的关系

一致的部分：深色点阵画布、冷蓝描边卡片、运行中橙色高亮、状态 pill、
终端/数据条、右上角端口、节点之间的连接意象。

没搬过来的部分：左侧「会话节点」列表、卡片之间的贝塞尔连线和「说明」标签。
原因是这一版的主体仍是**四栏平铺**——四块等宽会话面板；如果加左侧节点栏，
四栏会被压窄，平铺功能本身也会变形。如果更想要任务分派那张图的完整结构，
可以再出一版「左栏 + 画布」的布局，但那就不是平铺面板了。

## 文件

- `index.html` —— 静态结构（四节点示例会话）
- `scifi.css` —— 变量、背景、顶栏、状态条、通用控件
- `node-shell.css` —— 栅格、节点外壳、节点头部、分隔条
- `nodes.css` —— 节点内部日志、终端、批注、数据条、运行记录
- `cards.css` —— 任务卡、错误块、进度、消息、章节、列表、编号条目
- `composer.css` —— 输入区、发送按钮、页脚状态
- `motion.js` —— 节点光环、星尘粒子、鼠标柔光、截图定格模式
- `preview.png` —— 1920 × 1080 静态截图
- `preview.gif` —— 960 × 540 动效演示

## 落地注意

1. 目前是纯静态稿，按钮只有 hover，不会真的拖拽/发送。
2. 四节点内容按 1920 宽、约 460px/栏调过；窄窗口需要再收字号和装饰。
3. 颜色都写死在 CSS 变量里，接入主题时要映射到 `--dsw-*` token，或作为独立深色主题。
4. 每个节点有独立的 `NODE 01` / 状态 pill / 端口；真实接入时这些应该来自窗格数据。
5. 背景点阵和横向纹理是纯 CSS/渐变，没有外部图片依赖。
6. `?t=秒数` 是给无头浏览器截图用的定格模式：会把所有 CSS 动画定格到那一秒，
   方便合成 GIF；正常打开页面不会带这个参数。
